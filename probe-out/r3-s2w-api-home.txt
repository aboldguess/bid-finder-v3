                        <div class="tab-pane fade show active" id="pills-noticelist" role="tabpanel" aria-labelledby="pills-noticelist-tab">
                            <p>You can query the API to get a list of notices by calling this page:</p>
                            <p style="padding-left:20px;"><strong>https://api.sell2wales.gov.wales/v1/Notices</strong></p><br />
                            <p>Optionally you can also specify parameters in the request:</p>
                            <ul class="myul">
                                <li><strong>dateFrom</strong><br />The month and year for the range (in the format 'mm-yyyy'), that the notice was published. <i>Default is the current month.</i></li>
                                <li><strong>noticeType</strong><br />The notice type. See notice type below. <i>Default is notice type 2 (contract notice).</i></li>
                                <li><strong>outputType</strong><br />The output type of the notices returned. Use <strong>0</strong> for OCDS output or <strong>1</strong> for TED/custom output. <i>Default is 0.</i></li>
                                <li><strong>locale</strong><br />en = 2057, cy = 1106</li>
                            </ul>
                            <p>Note:</p>
                            <ul>
                                <li>If no values are given, default values will be used.</li>
                            </ul>
                            <div class="card" style="margin-top:20px;">
                                <div class="card-header bg-info">Example queries</div>
                                <div class="card-body">

                                    <p>Example 1: Fetch list of Contract Notices for the month of April, 2019 and return in OCDS format.</p>
                                    <pre class="egtext">https://api.sell2wales.gov.wales/v1/Notices?dateFrom=04-2019&amp;noticeType=2&amp;outputType=0&amp;locale=2057</pre>

                                    <p>Example 2: Fetch list of Contract Award Notices for the current month. Return in TED/custom format.</p>
                                    <pre class="egtext">https://api.sell2wales.gov.wales/v1/Notices?noticeType=3&amp;outputType=1</pre>

                                </div>
                            </div>
                        </div>
                        <div class="tab-pane fade" id="pills-noticedetail" role="tabpanel" aria-labelledby="pills-noticedetail-tab">
                            <p>You can query the API to get a family of notices by calling this page:</p>
                            <p style="padding-left:20px;"><strong>https://api.sell2wales.gov.wales/v1/Notice</strong></p><br />
                            <p>The request <u>requires</u> one parameter:</p>
                            <ul class="myul">
                                <li><strong>id</strong> - The OCID of the notice you want to retrieve.</li>
                                <li><strong>locale</strong> - en = 2057, cy = 1106</li>
                            </ul>
                            <div class="card" style="margin-top:20px;">
                                <div class="card-header bg-info">Example queries</div>
                                <div class="card-body">

                                    <p>Example 1: Fetch notice family for a notice with an OCID of &#39;ocds-kuma6s-0000517932&#39;</p>
                                    <pre class="egtext">https://api.sell2wales.gov.wales/v1/Notice?id=ocds-kuma6s-0000517932&amp;locale=2057</pre>

                                </div>
